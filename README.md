# Naawi-Oodena | Web Project 4

**A creative website showing my vision of what Naawi-Oodena could look and feel like in the future.**

For this school project, I designed a website inspired by the Naawi-Oodena development in Winnipeg. I focused on the idea of a community that brings together culture, housing, education, recreation, and local businesses.

I wanted this project to feel different from a basic information website, so I put more effort into visuals, layout, and the overall experience.

## What I built
- A homepage with a looping background video.
- An exploration page showing different parts of the community concept.
- A contact page with a styled form.
- Custom layouts, visual effects, and navigation across three pages.
- Embedded video and links to resources about the development.

The contact form is a demonstration and does not send emails.

## Technologies used
- **HTML** to build the pages and content.
- **CSS** to design the layout, colours, and effects.
- **Video and images** to make the website more engaging.

## What I learned
This project helped me become more confident with front-end design. I experimented with bigger layouts, media, and how a website can tell a story instead of just displaying information.

## How to view it
Open `index.html` in a browser or through VS Code Live Server.

**Project note:** This is my own creative interpretation of a possible future, not an official Naawi-Oodena website or a confirmed development plan. The website's section images were generated using ChatGPT, and the written concept was informed by the Kapyong Barracks Master Plan.

**Why it's on my GitHub:** It shows how my design skills developed and how I started building more visually detailed websites.
